MySQL 架构：锁查询

要点：锁查询。

宇宙超级无敌美少女数据库MySQL

锁查询#

（1）查询表是否有锁

show open tables from ceshi;

当 in_use 大于0 则表示当前表存在 锁 。

select * from `performance_schema`.table_handles where object_name='tmp_demo1';

当 _lock 字段有值时表示当前有元数据锁。

select * from `performance_schema`.data_locks where object_name='tmp_demo1';

当该表存在数据，则数据有行锁。

（2）元数据锁

select * from `performance_schema`.metadata_locks where  object_name='tmp_demo1'

若该表中有数据，则表示当前表存在元素据锁，可以查询、新增、修改、删除数据，但无法修改表结构、重命名等。

获取 event 的id: owner_event_id=24

获取 thread 的id: owner_thread_id=123

查询SQL:

  • 当前语句事件表，每个线程只显示一行最近被监视语句事件的当前状态。

    select * from performance_schema.events_statements_current where thread_id='123' and end_event_id='24';

  • 最近的语句事件历史表，每个线程默认保留10行事件历史信息

    select * from performance_schema.events_statements_history where thread_id='123' and end_event_id='24';

  • 长语句历史事件表，默认所有线程保留10000行事件历史信息

    select * from performance_schema.events_statements_history_long where thread_id='123' and end_event_id='24';

解决锁：

select * from `performance_schema`.threads where thread_id='123';

获取 processlist 的id: processlist_id=82

杀掉会话 ： kill 82

（3）行锁

select * from `performance_schema`.data_locks where object_name='tmp_demo1';

若该表中有数据，则表示当前表存在行锁，可以查询，锁定的行无法新增、修改、删除数据等。

获取 thread 的id: thread_id=56

查询SQL:

  • 当前事务事件信息表，每个线程只保留一行最近事务的事务事件。

select * from performance_schema.events_transactions_current where thread_id='56'

获取 event 的id: end_event_id=54

  • 最近的语句事件历史表，每个线程默认保留10行事件历史信息

select * from performance_schema.events_statements_history where thread_id='56' and end_event_id>='54';

解决锁：

select * from `performance_schema`.threads where thread_id='56';

获取 processlist 的id:processlist_id=15

杀掉会话 ：kill 15
