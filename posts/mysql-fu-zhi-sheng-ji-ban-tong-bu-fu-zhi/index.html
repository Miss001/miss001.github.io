MySQL 复制：升级半同步复制

前提： 主服务器：HOST_IP:3306 从服务器：HOST_IP:3306 主/从服务器show variables like '%have_dynamic_loading%'…

宇宙超级无敌美少女数据库MySQL

前提：

主服务器：<HOST_IP>:3306

从服务器：<HOST_IP>:3306

  • 主/从服务器show variables like '%have_dynamic_loading%';为YES
  • 主从复制已经开启并且有效
  • 一定不能配置多个复制通道，半同步复制仅与默认复制通道兼容

主服务器

  1. 检查环境，YES即可
show variables like '%have_dynamic_loading%';
  1. 登陆主节点
mysql –uroot –p<PASSWORD>
  1. 下载插件
INSTALL PLUGIN rpl_semi_sync_master SONAME'semisync_master.so';
  1. 查看插件
SHOW PLUGINS;
  1. 启用半同步复制
SET GLOBAL rpl_semi_sync_master_enabled = 1;
  1. 配置超时时间，默认10秒（10000）
SET GLOBAL rpl_semi_sync_master_timeout = 1000;
  1. 修改配置文件my.cnf
rpl_semi_sync_master_enabled = 1
rpl_semi_sync_master_timeout = 1000

从服务器

  1. 检查环境，YES即可
show variables like '%have_dynamic_loading%';
  1. 登陆主节点
mysql –uroot –p<PASSWORD>
  1. 下载插件
INSTALL PLUGIN rpl_semi_sync_slave SONAME'semisync_slave.so';
  1. 查看插件
SHOW PLUGINS;
  1. 停止复制线程
STOP SLAVE IO_THREAD;
  1. 启用半同步复制
SET GLOBAL rpl_semi_sync_slave_enabled = 1;
  1. 配置超时时间，默认10秒（10000）
START SLAVE IO_THREAD;
  1. 修改配置文件my.cnf
rpl_semi_sync_slave_enabled = 1

查看参数

SHOW VARIABLES LIKE 'rpl_semi_sync%';

rpl_semi_sync_master_enabled在主服务器上启用半同步复制

rpl_semi_sync_master_timeout控制主机在超时并恢复到异步复制之前等待提交来自从机的确认的时间

rpl_semi_sync_slave_enabled在从服务器上启用半同步复制

查看状态

  SHOW STATUS LIKE 'Rpl_semi_sync%';

Rpl_semi_sync_master_status 监视主服务器当前是使用异步还是半同步复制

Rpl_semi_sync_master_clients 查看连接了多少个半同步从站

Rpl_semi_sync_master_yes_tx从站成功确认的提交数

Rpl_semi_sync_master_no_tx从站未成功确认的提交数

Rpl_semi_sync_slave_status半同步复制当前是否在从站上运行
